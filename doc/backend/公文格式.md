# 后端产出的公文格式要求：
1. 整体要求：这个公文是遵循《党政机关公文格式》国家标准（GB/T 9704-2012）
2. 红头文件要求单倍行距，无首行缩进。左右缩进各-2cm。颜色正红色(#FF0000)。字体宋体，字号小初
3. 文号单独成段，段落左右缩进各-2cm。有边框底纹，只在底部。宽度1.5磅。颜色为正红色。
4. 文档标题：无缩进居中 宋体 3号 段前1倍行距，段后0.5被行距
5. 主送机关：无缩进靠左。
6. 正文部分：左右无缩进 首行缩进2个字符。按照公文格式要求对不同段落进行对应字体的修改。段落间距28磅
7. 附注部分：左右无缩进 首行缩进2字符。
8. 抄送单位：仿宋4号字体。左对齐，不缩进
9. 印发单位和引发日期： 两边对其。
